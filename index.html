1. Random number generators and seeds

A computer cannot produce truly random numbers from arithmetic alone. System.Random is a pseudo-random number generator (PRNG): a deterministic algorithm that starts from an internal state and produces a sequence that looks random. The starting value that sets that state is the seed.

Key idea: same seed, same runtime, same sequence of calls gives the same numbers every time. That is a feature for testing and replays, and a weakness for security.

The Next methods

Example: seeded vs unseeded

using System;

var a = new Random(42);
var b = new Random(42);   // same seed as a
var c = new Random();      // runtime picks the seed

for (int i = 0; i < 3; i++)
    Console.WriteLine($"a={a.Next(1, 7)}  b={b.Next(1, 7)}  c={c.Next(1, 7)}");
a and b print identical columns every run.
c changes from run to run.
(Example shape: a=6 b=6 c=2 / a=3 b=3 c=5 / a=1 b=1 c=1)

The exact numbers produced by a seeded Random are not guaranteed to stay the same across different .NET versions, so do not store them as expected values in long-lived tests. Within one runtime they are repeatable.

Live demo: why a seed repeats

This uses a simple linear congruential generator, state = (state × 1103515245 + 12345) mod 2³¹, to show the idea. It is an illustration, not the algorithm inside .NET.

Good habits

  • Create one Random and reuse it. In older .NET Framework, creating several in quick succession could give the same time-based seed and identical numbers.
  • In .NET 6+, Random.Shared is a ready-made, thread-safe instance.
  • Use a fixed seed when you need a replayable run (debugging, unit tests, simulations).
  • For passwords, tokens and keys use System.Security.Cryptography.RandomNumberGenerator, which is cryptographically secure. Random is predictable if someone learns its state.
  • Off-by-one trap: the upper bound of Next(min, max) is exclusive. A 20-sided die is Next(1, 21).

Example: secure random vs Random

using System;
using System.Security.Cryptography;

int pin = RandomNumberGenerator.GetInt32(1000, 10000);  // 1000..9999, secure
int die = Random.Shared.Next(1, 7);                    // 1..6, fine for games
Console.WriteLine($"PIN {pin}, die {die}");
PIN 5821, die 4   (values vary)

Worked practice (answers filled in)

Q: Write the call for a random even number from 0 to 98.
A: rnd.Next(0, 50) * 2. Next(0, 50) gives 0..49, doubled gives 0, 2, ... 98.

Q: Write the call for a random double from 5.0 up to (not including) 10.0.
A: 5.0 + rnd.NextDouble() * 5.0. Scale the 0..1 range by the width, then shift by the minimum.

Q: Two new Random(100) objects each call Next(1, 7) five times. How do the results compare?
A: Identical, in the same order, because both start from the same state.

2. Two's complement binary

Two's complement is how nearly every CPU stores signed integers. In an n-bit number the leftmost bit has weight −2n−1 instead of +2n−1. All other bits keep their normal positive weights.

Range for n bits: −2n−1 to 2n−1 − 1. For 8 bits that is −128 to 127. There is one more negative number than positive, and only one zero.

Negating a number: invert, then add 1

Example: write −5 in 8 bits.

  5      = 0000 0101
  invert = 1111 1010
  add 1  = 1111 1011   ← this is -5

  check with weights: -128 + 64 + 32 + 16 + 8 + 2 + 1 = -5

Reading a negative pattern

Example: what is 1111 0000 as a signed byte?

  1111 0000
  invert = 0000 1111
  add 1  = 0001 0000 = 16
  so 1111 0000 = -16
  check: -128 + 64 + 32 + 16 = -16

Why hardware uses it

  • Subtraction is addition: a − b is a + (−b), so one adder circuit does both.
  • No negative zero (sign-magnitude has +0 and −0).
  • Sign extension is simple: to widen a number, copy the sign bit leftwards. 1111 1011 (−5) becomes 1111 1111 1111 1011 in 16 bits.

Add it up: 5 + (−5) in 8 bits

    0000 0101   (5)
  + 1111 1011   (-5)
  -----------
  1 0000 0000   the carry out of bit 7 is discarded
    0000 0000   = 0

In C#

using System;

sbyte x = -5;
Console.WriteLine(Convert.ToString((byte)x, 2).PadLeft(8, '0'));   // bit pattern of the byte
Console.WriteLine(Convert.ToString(-5, 2));                          // int: all 32 bits
Console.WriteLine(sbyte.MinValue + " to " + sbyte.MaxValue);
Console.WriteLine(~5 + 1);                                           // invert + 1 = negate

sbyte big = 127;
unchecked { big++; }                                       // wraps around
Console.WriteLine(big);
try { int m = int.MaxValue; checked { m++; } }
catch (OverflowException) { Console.WriteLine("checked caught overflow"); }

C# arithmetic on integers is unchecked by default for non-constant expressions, so int.MaxValue + 1 silently wraps to int.MinValue (−2,147,483,648). Use checked when overflow must be an error.

Common slip: two's complement of 0 is 0 (invert gives 1111 1111, add 1 gives 1 0000 0000, the carry is dropped). And the most negative value, 1000 0000 (−128), is its own negation, which is why Math.Abs(int.MinValue) throws.

Q: 100 + 50 in an 8-bit signed byte?
A: 0110 0100 + 0011 0010 = 1001 0110, which reads as −106. Overflow: the true answer 150 is above 127. Overflow occurs when two numbers of the same sign give a result of the opposite sign.

3. for loops

A for loop packs the three parts of a counted loop into one header:

for (initializer; condition; iterator)
{
    body
}

Execution order: initializer runs once. Then repeat: test the condition; if true run the body, then the iterator; if false stop. The condition is tested before every pass, so a loop may run zero times.

Example: counting up, down and by steps

using System;

for (int i = 1; i <= 5; i++)  Console.Write(i + " ");
Console.WriteLine();
for (int i = 3; i > 0; i--)   Console.Write(i + " ");
Console.WriteLine();
for (int i = 0; i <= 20; i += 5) Console.Write(i + " ");
Console.WriteLine();
1 2 3 4 5
3 2 1
0 5 10 15 20

Nested loops, break and continue

using System;

// multiplication grid 3 x 3
for (int r = 1; r <= 3; r++)
{
    for (int c = 1; c <= 3; c++)
        Console.Write((r * c).ToString().PadLeft(3));
    Console.WriteLine();
}

// continue skips the rest of this pass; break leaves the loop
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0) continue;
    if (i > 7)      break;
    Console.Write(i + " ");
}
  1  2  3
  2  4  6
  3  6  9
1 3 5 7
Pitfalls
  • Off-by-one: for an array of length 5 the valid indexes are 0..4. i <= arr.Length throws IndexOutOfRangeException on the last pass.
  • Infinite loops: for (;;) has no condition, so it never ends unless something inside breaks out. Counting down with i++ against i > 0 never ends either.
  • Scope: a variable declared in the initializer (int i) does not exist after the loop. Declare it before the loop if you need its final value.
  • Modifying the counter inside the body makes loops hard to read. Prefer foreach when you do not need the index.
  • break in a nested loop only leaves the innermost loop.

Worked practice (answers filled in)

Q: How many times does for (int i = 2; i < 20; i += 4) run its body, and what are the values?
A: 5 times: 2, 6, 10, 14, 18. The next value, 22, fails the test.

Q: Write a loop that prints the even numbers from 10 down to 0.
A: for (int i = 10; i >= 0; i -= 2) Console.Write(i + " "); prints 10 8 6 4 2 0.

Q: What does for (int i = 0; i < 3; i++) for (int j = 0; j < 2; j++) count++; add to count?
A: 3 × 2 = 6.

4. switch

A switch chooses one branch by comparing a single value against several constants. It is tidier than a long if / else if chain when you test one value for many exact matches.

Classic switch statement

using System;

int day = 6;
switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;
    case 6:
    case 7:                          // stacked labels share one body
        Console.WriteLine("Weekend");
        break;
    default:
        Console.WriteLine("Another weekday");
        break;
}
Weekend
No implicit fall-through. Unlike C, C++ or Java, a C# case section that contains statements must end with break, return, throw, continue or goto. Forgetting it is compile error CS0163. Only empty stacked labels such as case 6: case 7: may share a body. To jump deliberately use goto case 1;.

goto case and default

int n = 2;
switch (n)
{
    case 1: Console.Write("A"); break;
    case 2: Console.Write("B"); goto case 1;
    default: Console.Write("?"); break;
}
BA

Switch expression (C# 8) and patterns (C# 7 to 9)

using System;

int score = 83;
string grade = score switch
{
    >= 90 => "A",            // relational pattern (C# 9)
    >= 80 => "B",
    >= 70 => "C",
    _     => "F"            // discard = the default arm
};
Console.WriteLine(grade);

object thing = 42;
string desc = thing switch
{
    int i when i < 0 => "negative int",   // when = guard
    int i              => $"int {i}",
    string s           => $"text '{s}'",
    null               => "nothing",
    _                  => "something else"
};
Console.WriteLine(desc);
B
int 42
  • Arms are tested top to bottom, and the first match wins, so put specific patterns before general ones.
  • If no arm matches and there is no _, the compiler warns and the runtime throws SwitchExpressionException.
  • A switch expression produces a value; a switch statement runs statements.

Switch inside a for loop

for (int i = 1; i <= 5; i++)
{
    switch (i)
    {
        case 3: break;                // leaves the switch only
        default: Console.Write(i + " "); break;
    }
}
1 2 4 5

Inside a switch, break ends the switch, not the surrounding loop. Use continue to move to the next loop pass, or return to leave the method.

Worked practice (answers filled in)

Q: Does this compile? case 1: Console.Write("x"); case 2: Console.Write("y"); break;
A: No. Case 1 has a statement and no break, which is error CS0163. Fix: add break; after the first statement, or goto case 2; if you want to continue.

Q: Rewrite if (c == 'a' || c == 'e') v = true; else v = false; as a switch expression.
A: bool v = c switch { 'a' or 'e' => true, _ => false }; (or patterns need C# 9).

Putting it together: seeded dice tally

This program uses all four topics: a seeded Random, a for loop, a switch expression, and a binary display of the result.

using System;

var rnd = new Random(2026);          // fixed seed: replayable
int[] tally = new int[7];            // index 1..6 used
int evens = 0;

for (int roll = 0; roll < 60; roll++)
{
    int face = rnd.Next(1, 7);
    tally[face]++;
    string kind = face switch
    {
        2 or 4 or 6 => "even",
        _           => "odd"
    };
    if (kind == "even") evens++;
}

for (int f = 1; f <= 6; f++)
    Console.WriteLine($"{f} ({Convert.ToString(f, 2).PadLeft(3, '0')}): {tally[f]}");
Console.WriteLine($"Even rolls: {evens} of 60");
