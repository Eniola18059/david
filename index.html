Variables and data types, from zero.

Every program stores information and does something with it. This page teaches how that storage works, what kinds of information exist, and the mistakes beginners make. Pick Python or JavaScript above; the ideas are the same in both.

1. What is a variable?

A variable is a named place in memory that holds a value. Picture a storeroom of boxes. Each box has a label (the name) and something inside (the value). When you need the value, you ask for it by its label.

age25name"Ada"is_membertrue

You create a variable with assignment: the name on the left, an equals sign, the value on the right. Read = as "put this value into that box", not as the maths "is equal to".

age = 25
name = "Ada"
print(name, "is", age)   # Ada is 25
let age = 25;
const name = "Ada";
console.log(name, "is", age);   // Ada is 25

Changing a value

The whole point is that the contents can change. The right side is worked out first, then stored.

score = 10
score = score + 5      # right side: 10 + 5 = 15, then stored
print(score)           # 15
score += 1             # shortcut for score = score + 1
print(score)           # 16
let score = 10;
score = score + 5;     // right side: 10 + 5 = 15, then stored
console.log(score);    // 15
score += 1;            // shortcut for score = score + 1
console.log(score);    // 16

JavaScript has three keywords. let makes a variable you can change. const makes one you cannot reassign. var is the old way; avoid it. Default to const, and switch to let when you need to change it.

Python has no keyword for this. Writing name = value creates the variable. By convention, constants are written in capitals, such as MAX_USERS = 100, but Python will not stop you from changing them.

Why not just use the raw value?

Variables give values meaning (tax_rate says more than 0.075), let you reuse a value in many places, and let you change it in one place only.

3. What is a data type?

A value is more than its content. 5 and "5" look alike, but the first is a number you can do maths with and the second is text. The data type tells the computer what kind of thing a value is, and therefore what you are allowed to do with it. You can multiply numbers; you can convert text to uppercase; you cannot do the reverse.

Kind of dataPythonJavaScriptExample
Whole numbersintnumber42, -7
Decimal numbersfloatnumber3.14
Textstrstring"hello"
True or falseboolbooleanTrue / true
NothingNonenull, undefinedno value yet
Ordered listlistArray[1, 2, 3]

Ask the language what type something is:

print(type(42))        # <class 'int'>
print(type("42"))      # <class 'str'>
print(type(3.14))      # <class 'float'>
console.log(typeof 42);      // "number"
console.log(typeof "42");    // "string"
console.log(typeof 3.14);    // "number"

Both languages are dynamically typed: you do not declare a type, and the variable takes the type of whatever it currently holds. Languages like Java and C# are statically typed, where you write the type up front (int age = 25;).

4. Numbers

price = 1200          # int
rate = 0.075          # float
print(price * rate)   # 90.0
print(7 / 2)          # 3.5   normal division
print(7 // 2)         # 3     whole-number division
print(7 % 2)          # 1     remainder
print(2 ** 10)        # 1024  power
const price = 1200;
const rate = 0.075;
console.log(price * rate);        // 90
console.log(7 / 2);               // 3.5
console.log(Math.floor(7 / 2));   // 3   whole-number division
console.log(7 % 2);               // 1   remainder
console.log(2 ** 10);             // 1024

The famous surprise. Computers store decimals in binary, and some decimals cannot be stored exactly. 0.1 + 0.2 gives 0.30000000000000004 in both languages. For money, work in the smallest unit (kobo or cents, as integers) or use a decimal library, and round only when displaying.

5. Strings (text)

A string is a sequence of characters inside quotes. Single and double quotes both work; just close with the same kind you opened with.

first = "Ada"
last = 'Lovelace'
full = first + " " + last          # joining: "Ada Lovelace"
print(f"Hello, {full}!")           # f-string inserts variables
print(len(full))                   # 12
print(full[0], full[-1])           # A e   (index starts at 0)
print(full.upper())                # ADA LOVELACE
print(full[0:3])                   # Ada   (slice)
const first = "Ada";
const last = 'Lovelace';
const full = first + " " + last;       // joining: "Ada Lovelace"
console.log(`Hello, ${full}!`);        // template literal
console.log(full.length);              // 12
console.log(full[0], full.at(-1));     // A e   (index starts at 0)
console.log(full.toUpperCase());       // ADA LOVELACE
console.log(full.slice(0, 3));         // Ada

Two things to remember. Counting starts at 0, so the first character is at position 0. And strings are immutable: methods like upper() give you a new string and leave the original untouched.

6. Booleans

A boolean has exactly two possible values, true or false. They come from comparisons and decide which code runs.

age = 17
can_vote = age >= 18          # False
print(can_vote)
print(age > 10 and age < 20)  # True   both must be true
print(age < 10 or age > 60)   # False  one is enough
print(not can_vote)           # True   flips it
print(5 == 5, 5 != 5)         # True False
const age = 17;
const canVote = age >= 18;           // false
console.log(canVote);
console.log(age > 10 && age < 20);   // true   both must be true
console.log(age < 10 || age > 60);   // false  one is enough
console.log(!canVote);               // true   flips it
console.log(5 === 5, 5 !== 5);       // true false

Truthy and falsy. Conditions also accept non-boolean values. Falsy values count as false: zero, an empty string, an empty collection, and nothing. Almost everything else is truthy.

= assigns, == compares. Mixing them up is a classic first bug.

= assigns, === compares strictly. Use ===, not ==, because == converts types quietly ("5" == 5 is true).

7. Nothing at all

Sometimes a variable exists but has no value yet, such as a user's middle name or a search that found no results. That is its own type.

middle_name = None
if middle_name is None:
    print("No middle name")
let middleName = null;      // you chose "nothing"
let city;                   // undefined: never given a value
if (middleName === null) console.log("No middle name");
console.log(city);          // undefined

Using nothing as if it were something is behind a huge share of real-world crashes, so check for it before you use a value.

8. Collections: many values in one variable

Lists (arrays): ordered items

fruits = ["mango", "pawpaw", "orange"]
print(fruits[0])            # mango
fruits.append("banana")     # add to the end
fruits[1] = "guava"         # change an item
print(len(fruits))          # 4
const fruits = ["mango", "pawpaw", "orange"];
console.log(fruits[0]);     // mango
fruits.push("banana");      // add to the end
fruits[1] = "guava";        // change an item
console.log(fruits.length); // 4

Dictionaries (objects): labelled items

When items have meaning by name rather than position, use key and value pairs.

user = {"name": "Ada", "age": 25, "active": True}
print(user["name"])         # Ada
user["email"] = "ada@example.com"   # add a key
const user = { name: "Ada", age: 25, active: true };
console.log(user.name);     // Ada
user.email = "ada@example.com";     // add a key

Collections can hold any type, including other collections. A list of user dictionaries is how most real data looks. A const object or array can still have its contents changed; const only stops you pointing the name at something else.

9. Converting between types

Data from forms, files and the web usually arrives as text, even when it looks like a number. Convert it before doing maths.

typed = "25"
print(typed + typed)        # "2525"  text joined, not added
age = int(typed)
print(age + 1)              # 26
print(float("3.5"), str(99), bool(0))   # 3.5 99 False
int("hello")                # ValueError: cannot convert
const typed = "25";
console.log(typed + typed);       // "2525"  text joined, not added
const age = Number(typed);
console.log(age + 1);             // 26
console.log(Number("3.5"), String(99), Boolean(0));  // 3.5 "99" false
console.log(Number("hello"));     // NaN (not a number)

Mixing types can fail loudly or silently. Python raises an error for "age: " + 25. JavaScript quietly gives "age: 25" and also "5" * 2 = 10 but "5" + 2 = "52". Convert on purpose so you never rely on guesses.

Common mistakes

Using a variable before creating it. Misspelling a name or changing its case. Forgetting quotes around text (name = Ada looks for a variable called Ada). Doing maths on text that came from input. Starting counts at 1 instead of 0. Choosing vague names like x that you cannot understand next week.
